# BusyBoy 0.2.0 使用说明

一台直接放在桌面上的待办打印机。写下一件事，看着它从出纸口慢慢打印出来；完成以后用马克笔划掉。

[下载应用](https://github.com/Kwinliu/BusyBoy/releases/latest) · [下载 PDF 说明书](../output/pdf/BusyBoy-User-Guide-zh-CN.pdf) · [返回首页](../README.md)

## 1. 安装与第一次启动

**适用系统：macOS 14 或更新版本，Apple Silicon Mac。**

1. 下载 Release 中的 `BusyBoy-v0.2.0-macOS-arm64.zip`。
2. 解压，把 `BusyBoy.app` 放入“应用程序”，双击打开。
3. 打印机会出现在桌面上，菜单栏也会出现打印机图标。应用没有普通主窗口和 Dock 图标。

当前发行包尚未进行 Apple Developer ID 签名和公证。首次打开可能出现来源检查提示；只使用你信任的仓库 Release，并按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 查看系统处理方式。不要关闭整台 Mac 的安全保护。

## 2. 写下第一条待办

按 **Control + Option + Space（⌃⌥Space）** 呼出输入框，或点击机身上的 **+**。

![输入框中填写示例待办](screenshots/quick-entry.png)

| 按键 | 作用 |
| --- | --- |
| Return | 打印当前内容 |
| Shift + Return | 在一条待办中换行 |
| Esc | 收起输入框，暂存草稿 |
| 再按 ⌃⌥Space | 输入框在前台时收起；在后台时重新聚焦 |

每条待办支持 1–500 个字符。中文输入法选词时不会提前打印，先完成选词，再按 Return 提交。

提交后绿灯先闪烁接收，再按分段节奏慢速走纸。连续输入的待办会排队打印。内容较长时可以用滚轮或触控板翻看纸条，纸旁不会出现滑块。

## 3. 完成、编辑与撕纸

- **完成一件事**：点击纸上的文字，毛糙的马克笔会划掉该事项。再点一次恢复待办。
- **修改内容**：右键点击事项，选择编辑。保存后更新原事项。
- **删除事项**：右键点击事项，选择删除；可撤销最近一次清单更改。
- **撕下当前纸条**：点击剪刀贴纸，纸条会向下撕离。纸上的事项进入历史，不会被永久清除。
- **找回刚撕下的纸**：使用 `⌘Z`，或设置菜单中的“撤销上次更改”。撤销是单步的，退出应用后不保留撤销记录。

打印过程中不能撕纸。查看历史时也不能撕当前纸条。通过“撕下的纸条”查看归档，切回“全部事项”返回当前纸条。

## 4. 机身上的三张工具贴纸

再次点击同一张贴纸可收回面板。收起时完整背板仍在机身后面，由机身自然遮挡；展开时亮镍关节随动。

### 地球：世界时钟

默认显示伦敦和墨西哥城。刻度直接印在 A 型背板上，黑色时分针、红色圆头秒针带投影；LON / MEX 位于刻度圈内。

![世界时钟展开](screenshots/world-clocks.png)

点击一个时钟即可搜索并更换城市。城市检索需要联网；时钟按城市的时区计时，并自动处理夏令时。

### 太阳云朵：天气

默认显示长春天气。点击城市名称或右下角菜单可以更换城市、刷新天气。

天气与城市搜索需要网络，不需要定位权限。服务暂时不可用时会提示；有缓存时可继续查看上次结果。天气数据由 Open-Meteo 提供，数值随城市和时间变化。

### 闹钟：番茄、时钟与闹钟

绿色 LED 屏显示倒计时。默认专注 25 分钟、休息 5 分钟。

顶部可切换“番茄 / 时钟 / 闹钟”。“专注 / 休息”和闹钟开启状态、日期、重复方式均在绿屏数字左侧，数字下方不放文字。

- 三角形按键：开始；运行时变为暂停；暂停后可继续。
- 回转箭头：重置当前阶段。
- 专注 / 休息：在未运行时切换阶段。
- 齿轮：调整时长和结束提示音。专注 1–99 分钟，休息 1–30 分钟；运行时先暂停再调整时长。
- 面板收起后仍继续计时；退出应用后不会自动恢复倒计时。结束后手动开始下一阶段。

“时钟”以 24 小时制显示本地时、分、秒，下方显示日期和星期。切换到其他档位不会中断番茄计时。

![本地时钟](screenshots/digital-clock.jpg)

“闹钟”默认关闭。点击齿轮设置时间、每天或单次、开启和响铃选项；过了当天时间则安排在明天。设置和稍后提醒会保存在本机。到点弹出白框绿屏提醒，可停止或稍后五分钟；无人操作时一分钟后自动停止。隐藏打印机仍可提醒。

![状态位于数字左侧的闹钟](screenshots/alarm.jpg)

闹钟需要应用保持运行，不会唤醒睡眠中的 Mac。唤醒或重开应用时，五分钟内错过的提醒会补响；更早的会跳过。单次闹钟触发后关闭，每天闹钟继续安排下次。

[时钟与闹钟完整操作说明](CLOCK_AND_ALARM.zh-CN.md)

## 5. 移动、叠放与找回打印机

按住没有贴纸的顶盖或机身两侧拖动，松开鼠标放下，位置自动保存。纸张、贴纸和实体按钮用于各自操作，不能作为拖动点。

默认按普通窗口顺序叠放，其他应用可以盖住打印机。需要一直可见时，开启“保持在所有窗口最前”。关闭后恢复普通叠放顺序。

鼠标停留时，纸条下方会显示设置入口。菜单栏打印机图标也能操作：

- 显示桌面打印机；移回桌面右上角。
- 切换全部、待办、已完成和撕下的纸条。
- 开关机械与打印声音；开关窗口置顶。
- 撤销上次清单更改；导出 JSON 备份；打开本机数据文件夹。
- 退出 BusyBoy。

靠近屏幕上沿时，展开工具会临时下移打印机留出空间，收起后恢复；主动拖动后保留新位置。

## 6. 数据与备份

待办自动保存在：

```text
~/Library/Application Support/PaperTodo/todos.json
```

使用设置菜单或菜单栏中的“导出清单备份”，把 JSON 保存到你选择的位置。恢复备份时先退出应用，再将备份放回上面的路径，文件名使用 `todos.json`。恢复前保留原文件副本。

应用没有账户、云同步和遥测，不采集麦克风。声音在本机合成；只有天气与城市检索联网，不会发送待办内容。声音、城市、时长、位置及置顶等偏好在本机保存。

## 7. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 没有普通应用窗口 | 这是桌面程序，查看桌面和菜单栏打印机图标。 |
| 隐藏后找不到 | 菜单栏 → 显示桌面打印机；或重新打开应用。 |
| 打印机不在当前屏幕 | 菜单栏 → 移回桌面右上角。 |
| 快捷键不响应 | 先用机身 + 输入，检查其他应用是否占用了 ⌃⌥Space。 |
| 不能拖动 | 按住没有贴纸的机身顶盖或两侧，避开纸条和按钮。 |
| 其他应用挡住打印机 | 默认行为；有需要时开启置顶。 |
| 没有声音 | 检查“机械与打印声音”、Mac 音量和输出设备；番茄钟结束提示音有独立开关。 |
| 天气暂时不更新 | 检查网络后刷新；搜索城市时可试英文名。 |
| 数据读取错误 | 保留原 JSON 文件，不要用空文件覆盖；先备份，再检查或反馈。 |

当前版本不连接实体热敏打印机，不包含手机端、云同步或协作功能。截图中的演示数据不包含在首次正常启动的清单中。
